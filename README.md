# Calculator

A simple, responsive calculator built with plain HTML, CSS and JavaScript. No frameworks, no dependencies, and no `eval()`.

## Features

- Add, subtract, multiply, divide
- Percent, plus/minus toggle, backspace, clear
- Chained operations (`2 + 3 + 4`)
- Division by zero shows `Error`
- Keyboard support: digits, `+ - * /`, `Enter`, `Backspace`, `Esc`, `%`

## Run locally

Open `index.html` in any browser.

## Deploy on GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
4. Your site will be live at `https://<username>.github.io/<repo>/`.
